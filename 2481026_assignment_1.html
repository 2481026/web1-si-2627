Kisah Liburan Jessica

Nama : Jessica Shabrina
NIM : 2481026

Selama liburan, awalnya saya tidak ada rencana untuk pulang kerumah orang tua saya karena awalnya saya dijanjikan untuk bekerja oleh teman saya Ester Manurung untuk bekerja di Jakarta. Tapi, singkat cerita rencana tersebut tidak jadi karena Ester tidak memberikan kejelasan informasi yang lengkap. Jujur saya merasa kesal karena awalnya saya dan Ester sudah sepakat dan sama-sama excited, tapi kenyataannya berbeda, Ester malah bekerja di kampus UNAI. Tapi disisi lain saya bersyukur, akhirnya setelah satu setengah tahun, saya pulang kerumah orangtua saya untuk melepas rindu. Ini adalah pengalaman pertama saya pulang ke Sumatera menggunakan Kapal Laut sendirian. Awalnya perasaan saya campur aduk, takut, cemas dan lainnya. Tapi pengalaman ini cukup seru bagi saya, karena saya belajar mandiri dan belajar berinteraksi dengan orang baru dilingkungan kapal. Setelah saya sampai di rumah orangtua saya, kegiatan saya hanya jalan-jalan dengan teman SMP saya, membantu menyelesaikan raport orangtua saya dan membantu orangtua saya untuk membuat proposal kegiatan ketua jurusan untuk satu semester kedepan. Walaupun melelahkan, tapi setidaknya saya bisa bertemu langsung dan memantau kondisi kesehatan kedua orangtua saya. Saya menghabiskan waktu dengan orangtua saya untuk bercerita, memasak dan beribadah bersama. Ini adalah salah tau hal yang saya syukuri.

Pada saat dirumah, saya rasa waktu sangat cepat berlalu sampai saya kembali lagi ke Jakarta. Selama di Jakarta saya juga tidak melewatkan waktu untuk bertemu dengan teman-teman saya. Kami mengunjungi kota tua dan blok M Jujur saya sangat amat happy karena saya bisa bertemu teman-teman saya saat liburan. I mean vibes di asrama dan diluar asrama itu berbeda jadi kita bisa berkespresi lebih happy dan sangat ceria. Ini merupakan pengalaman yang luar biasa bagi saya, tapi lebih luar biasa kalau saya dapat tempat magang kayaknya. Dan saat kembali ke Kampus UNAI juga, saya dianter oleh keluarga dan bareng dengan Frida. Mungkin inilah pengalaman yang sangat berkesan bagi saya saat liburan tiga bulan ini. Terima Kasih.
